# Prime Number Checker (C++)

A C++ program that checks whether a given positive integer is a **Prime** or **Not Prime** number.

## 🚀 Features
- Validates user input to ensure a positive integer.
- Efficiently checks primality using a loop up to `N / 2`.
- Uses C++ `enum` for clear status representation.
